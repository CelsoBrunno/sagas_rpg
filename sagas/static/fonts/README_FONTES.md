# 📝 Fonte Mr Eaves Small Caps - Instalação

## 📋 Fonte Configurada

A fonte **Mr Eaves Small Caps** está configurada e sendo usada automaticamente nos PDFs gerados.

## 📁 Localização

A fonte está localizada em:
```
static/fonts/Mr Eaves/
```

## 📄 Arquivos de Fonte

O seguinte arquivo está disponível:
- `Mr Eaves Small Caps.otf` - Fonte regular (usada por padrão)

## ✅ Funcionamento

O sistema automaticamente:
- ✅ Detecta a fonte Mr Eaves Small Caps na pasta `static/fonts/Mr Eaves/`
- ✅ Registra com ReportLab na primeira geração de PDF
- ✅ Usa em todos os textos dos PDFs gerados
- ✅ Faz fallback para Helvetica-Bold se não encontrar

## 📚 Sobre a Fonte Mr Eaves Small Caps

A fonte Mr Eaves Small Caps é uma fonte elegante e clássica perfeita para fichas de personagem de RPG.
É a fonte oficial usada em materiais D&D 5e para cabeçalhos e títulos importantes.

## 🔄 Fallback

Se a fonte Mr Eaves Small Caps não for encontrada, o sistema automaticamente usa **Helvetica-Bold** como fallback.
